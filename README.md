
# Nmap Network Scanning

## Overview
This project demonstrates basic network scanning using Nmap.

## Objectives
- Discover active hosts on a network
- Identify open ports
- Understand common network services
- Learn basic reconnaissance techniques

## Tools Used
- Nmap
- Windows
- Command Prompt

## Skills Learned
- Network Scanning
- Host Discovery
- Port Scanning
- Network Reconnaissance

## Example Commands
nmap -sn 192.168.1.0/24
nmap localhost
nmap -F localhost
